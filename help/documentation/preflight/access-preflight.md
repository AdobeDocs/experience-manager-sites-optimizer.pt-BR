# Acessar o Preflight

A Comprovação está disponível nos ambientes de criação do AEM Sites, incluindo o Editor universal, a criação com base em documento e o Editor de páginas do AEM Sites. A comprovação é aberta como um painel na página que você está criando. No painel, você [executa auditorias](./audits.md) nessa página e a opção Comprovação [exibe todas as oportunidades](./audit-results.md) que encontrar para aprimorar a página antes da publicação.

* **Editor universal** – A extensão do Preflight aparece no **painel lateral**. Selecione-a para abrir o painel &#39;Comprovação&#39;.
* **Criação baseada em documentos** - Abra o painel Comprovação no Sidekick ou em um bookmarklet no conteúdo da página visualizada.
* **Editor de páginas do AEM Sites** - Use o bookmarklet de Comprovação no navegador para abrir o painel Comprovação.

Depois que o painel for aberto, selecione **Analisar página** para iniciar uma auditoria da página atual.

Para obter instruções de configuração, consulte [Configuração do Preflight](./setup.md).
