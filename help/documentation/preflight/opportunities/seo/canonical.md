# Auditoria canônica

A auditoria **Canônica** revisa o link canônico na sua página. Um link canônico correto informa aos mecanismos de pesquisa qual URL é a versão autoritativa de uma página, o que ajuda a evitar problemas de conteúdo duplicado. A auditoria sinaliza links canônicos que estão ausentes ou incorretos.

Quando a auditoria encontra oportunidades, cada uma descreve o problema e a alteração recomendada. Para saber como revisar e resolver oportunidades, consulte [Resultados de auditoria em Comprovação](../../audit-results.md).
