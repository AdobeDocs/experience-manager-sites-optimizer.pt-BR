# Auditoria Lorem ipsum

A auditoria **Lorem ipsum** detecta um texto de espaço reservado que foi deixado no conteúdo da página. A publicação de uma página com texto de espaço reservado parece inacabada para os leitores e pode ser indexada por mecanismos de pesquisa. A auditoria sinaliza qualquer texto de espaço reservado para que você possa substituí-lo por conteúdo real antes de publicar.

Quando a auditoria encontra oportunidades, cada uma identifica onde o texto do espaço reservado aparece. Para saber como revisar e resolver oportunidades, consulte [Resultados de auditoria em Comprovação](../../audit-results.md).
